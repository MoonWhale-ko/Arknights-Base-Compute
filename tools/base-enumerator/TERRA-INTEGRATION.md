# 특수 스킬 통합 실험판 — 2026-10-20

업로드한 Terra Archive v27 엔진을 기존 시간 시뮬레이터에 연결했습니다. 운영 사이트에는 배포하지 않았습니다. 이전 결과 파일은 변경하지 않습니다.

## 실행

```sh
node heuristic-cli.mjs --engine terra --input examples/quality-trading.json --output new-result.json --seconds 10
node --test *.test.mjs test.mjs
python -m http.server 8000
```

브라우저에서는 `http://localhost:8000/heuristic.html`을 엽니다. 계산은 Web Worker에서 수행되며 중단 버튼으로 종료할 수 있습니다. 비교용 `--engine legacy`도 유지합니다. JS API는 기존 호환성을 위해 기본 엔진을 legacy로 유지합니다.

## 연결한 내용

- 432명 원본 데이터와 현재 보유·정예화·레벨별 해금 상태.
- 원본의 자동화, 생산력 대체, 창고 변환, 진영/동료/시설 연계 평가.
- 실제 방 레벨, 실제 숙소 인원, 사무실 추가 모집 인원으로 연계 자원 재계산.
- 컨디션 경계값과 시간 경과형 스킬 변화를 시뮬레이션 시간 사건으로 반영.
- 2/3교대, 첫 소진/전원 소진/12시간 교대, 숙소 추가 조작, 고정 지원자와 상주자 검증.
- 사무실 최우선, 미보유 단서 우대 담당 최대 한 명과 속도 담당 조합, 생산 우선순위.
- 24시간 및 첫 사이클 결과, 기대 수익 시나리오, 드론 자연 회복량, 교대/숙소 변경 기록.
- 유넥티스 발전소 수 증가, 사무실→응접실, CONFESS 다른 발전소 조건, 시/링 경계 조건, 시즈/모건, 콜드샷 중첩, 페페 주문 보완.

## 검증과 한계

기존 70개 + 통합 16개 테스트가 통과했습니다. 통합 테스트에는 작은 사례의 독립 전수 열거와 2/3교대·세 교대 기준의 결과 대조가 포함됩니다. 이는 모든 스킬 조합의 게임 내 정답 검증이 아닙니다.

432명 전체 보유를 가정한 243 시설 예제에서 10초 실행: 16회 시간 시뮬레이션, 37,192회 구성 평가, 실행 오류 0건. 시간 제한으로 첫 시작 배치의 개선 탐색도 끝내지 못했습니다. 따라서 전체 최적해·99% 정확도 또는 완료율을 제시하지 않습니다. 측정 결과는 `TERRA-INTEGRATION-BENCHMARK.json`에 있습니다.

남은 정확도 검증 항목:

1. 제이는 실제 시설 레벨과 상한·대기 주문 수를 반영합니다. E1의 다른 인원 효율에 따른 상한 감소와 노시스 조합(+125%)을 검증했습니다. 시간 경과형·특수 중첩의 모든 조합은 독립 검증 전이며, 대기 주문은 기대값으로 누적하므로 게임의 개별 정수 주문 이벤트와 같지는 않습니다.
2. 고품질·위약·특별 주문의 대부분은 원본 효율 환산식입니다. 표시 범위는 두 시나리오의 기대값이며 확률적 신뢰구간이 아닙니다. 페페는 4.5시간/0순금/1,000용문폐, 클로저는 2.4시간/2순금/1,200용문폐, U-Official은 2.4시간/2순금/1,000용문폐의 주문을 별도로 적용합니다. 클로저·U-Official은 수주 속도 효과를 반영하고 페페는 영향을 받지 않습니다. 개별 정수 주문 완료가 아닌 기대 작업량 누적입니다.
3. 숙소 임의 단일 대상은 배치 순서상 첫 회복 필요 인원으로 정합니다. 모든 가능한 회복 대상의 최적화를 수행하지 않습니다.
4. 응접실 분위기 보정은 기존 실험식을 유지합니다. 단서 종류별 확률은 요청에 따라 계산하지 않습니다.
5. 훈련실·가공소는 다른 시설에 영향을 주는 배치를 표현하기 위해 포함합니다. 실제 훈련 진행·가공 작업과 소비 재료를 최적화하지 않습니다.
6. 이번 제이 수정 후에는 변경 범위의 통합 테스트 16개를 실행해 모두 통과했습니다. 기존 테스트 70개는 직전 변경에서 통과했으며 이번에는 재실행하지 않았습니다. 전체 스킬별 독립 게임 관측 대조 및 브라우저 화면 검증은 완료하지 않았습니다. 현재 브라우저 환경에서 로컬 file:// URL 접근이 보안 정책으로 거부되어 시각 검증을 진행하지 못했습니다. 후보 제외 0건은 지원 완료 또는 검증 완료라는 의미가 아닙니다.
