# 특수 스킬 통합 실험판 v2 — 2026-10-20

운영 사이트 배포 없이 별도 계산 프로그램을 보완한 버전입니다. 이전 카탈로그와 결과 파일은 보존합니다. 현재 보유 상태에 대한 제한 시간 탐색이며 전체 최적해를 보장하지 않습니다.

## 실행

```sh
node heuristic-cli.mjs --engine terra --input examples/quality-trading.json --output new-result.json --seconds 10
node --test *.test.mjs test.mjs
python -m http.server 8000
```

브라우저에서는 `http://localhost:8000/heuristic.html`을 엽니다. 기존 `index.html`과 `standalone.html`은 이전 실험 엔진입니다. 현재 통합 엔진을 확인하려면 `heuristic.html` 또는 위 CLI를 사용해야 합니다. 비교용 `--engine legacy`와 기존 JS API 기본값은 보존합니다.

## 검증 범위

기존 70개와 새 통합 검사 28개를 구분합니다. 새 검사에는 작은 사례의 독립 전수 열거, 교대·스킬 수치 대조, 숙소 개선, 주문 보상, 워커 실행이 포함됩니다. 432명 데이터의 시설별 프로필 598개를 컨디션 24/12/0에서 평가하여 유한 수치가 나오는지 검사했습니다. 이 검사는 모든 스킬 조합의 게임 내 정답 검증이 아닙니다.

전체 432명 보유를 가정한 243 기지의 10초 시험에서 18회 시간 시뮬레이션, 40,558회 구성 평가, 실행 오류 0건이었습니다. 제한 시간 내 첫 시작 배치의 개선 과정도 끝내지 못했습니다. 측정은 `TERRA-V2-BENCHMARK.json`에 남겼으며 기존 측정 파일은 그대로 보존합니다.

## 남아 있는 가정과 외부 제약

- 품질 분포는 공개된 기본/성숙 관측값입니다. 입실 초기 3/5시간의 연속 확률 곡선은 알려진 것으로 취급하지 않습니다. 두 시나리오는 실제 수익의 최소·최대 또는 통계적 신뢰구간이 아닙니다.
- 관측 자료가 없는 품질 중첩·저레벨 조합은 기본 분포를 사용하며 결과의 `trade.assumptions`에 `unobserved-quality-distribution`을 기록합니다.
- 주문은 기대 작업량으로 누적하므로 소수 주문이 생깁니다. 개별 무작위 주문을 추첨하거나 개별 정수 주문 완료·이월을 재현하지 않습니다.
- 숙소 탐색은 제한된 개선 탐색입니다. 임의 단일 대상 회복은 첫 회복 필요 입실자라는 모델을 유지하며, 게임의 임의 대상 선택 자체를 사용자가 직접 지정할 수 있다고 주장하지 않습니다.
- 훈련실·가공소는 다른 시설을 지원하는 배치를 표현합니다. 실제 훈련·가공 작업 일정이나 재료 소비 최적화는 이 계산기의 생산 목표가 아닙니다.
- 재료 충분·교대 시 수거·드론 미사용을 가정합니다. 첫 사이클 완료가 무한 반복 운영의 지속 가능성을 뜻하지는 않습니다.
- 모든 복합 스킬의 독립 게임 관측 대조는 완료되지 않았습니다. 후보 제외 0건이나 598개 실행 검사가 모든 효과의 정확도를 증명하지 않습니다.
- 브라우저 화면 조작 검증은 미완료입니다. 이 환경의 클라우드 브라우저가 로컬 `file://` URL을 보안 정책으로 차단했습니다. Node 워커 검사를 실제 화면 검증으로 대신 표기하지 않습니다. 배포 보류 상태를 유지합니다.
