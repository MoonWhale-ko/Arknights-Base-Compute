01 / 조건자료 읽는 중

전체 인원 자동 비교는 명단 입력 없이 보유·미보유와 해금 단계를 생성합니다. 최소·최대를 모두 10으로 하면 정확히 10명인 모든 명단을 비교합니다. 전체 범위는 현실적인 시간 안에 완주할 수 없는 규모입니다. 각 결과에 24시간 시점과 모든 조가 한 번씩 근무한 첫 사이클 완료 시점을 함께 저장합니다. 소진 교대 시점이 없거나 검사 상한까지 끝나지 않으면 ‘사이클 미완료’로 기록합니다.

시설 · 생산 품목 · 숙소 지원자 · 후보 제한

자동 생성 범위는 layoutSearch에서 변경합니다. allSupportBuilt는 개방된 우측 지원시설을 모두 건설하는 옵션이며, 숙소 개수는 dormCount로 따로 지정합니다. 고정 시설 모드에서는 JSON의 base.rooms, products, dormSupport, residents, candidates를 수정하세요. 현재 없는 단서는 options.missingClues에 1~7을 입력합니다. 사무실 → 미보유 단서 정책 → 응접실 속도 → 생산물 순위 → 무역소 예상 수익 순으로 비교합니다. options.clueExchangeActive는 단서 교류 상태입니다. 응접실은 미보유 단서 담당 최대 1명과 속도 담당으로 구성합니다. 무역소는 순금 거래의 기본/성숙 분포 시나리오 기대값 범위이며 실제 수익 보장 구간이 아닙니다. 초기 확률 변화는 재현하지 않습니다.
